# 使用另一个 GPT 账号的短视频流程

## 结论

可以换另一个 GPT 账号做。换账号只影响“生成提示词和标题”这一步，妙手、TikTok Creative Studio、Neobund 的流程不变。

推荐方式：

1. 自动化系统：使用新 GPT 账号对应的 OpenAI API Key。
2. 手动测试：使用新 GPT 账号登录 ChatGPT 网页，把产品图和描述发进去，让它输出提示词和标题。

## 自动化系统流程

### 1. 准备新 GPT 账号的 API Key

在新 GPT/OpenAI 账号里创建 API Key，然后配置到本机环境变量：

```powershell
$env:OPENAI_API_KEY="你的新API Key"
$env:OPENAI_MODEL="gpt-4.1"
```

不要把 API Key 写进明文配置文件，也不要发给别人。

### 2. 系统处理顺序

1. 妙手读取出单产品。
2. 提取产品名称、类目、国家、主图。
3. 如果主图有人脸，生成无脸产品裁图，避免 TikTok 拒绝。
4. 用新 GPT 账号生成 15 秒视频分镜提示词。
5. 用新 GPT 账号生成德国 TikTok 标题和标签。
6. 打开 TikTok Creative Studio 的 Create 页面。
7. 选择 Video。
8. 上传产品图。
9. 选择 Dreamina Seedance 2.0。
10. 设置时长 15s。
11. 粘贴 GPT 生成的视频分镜提示词。
12. 等待视频生成完成。
13. 下载视频。
14. 按类目匹配 Neobund/TikTok 发布账号。
15. 进入 Neobund 的 TikTok Publish。
16. 上传视频、填标题和标签。
17. 放入待确认队列，不自动发布。

### 3. 德国账号匹配规则

| 德国产品类型 | 发布账号 |
| --- | --- |
| 数码相关、手机壳 | hertermarwee.shop3 |
| 服装、鞋子、穿到身上的 | hertermarwee.shop4 |
| 饰品、包包 | hertermarwee.shop7 |
| 其他德国产品 | hertmarwee.shop |

## 手动 ChatGPT 网页流程

如果你只是想用另一个 GPT 网页账号测试，不用 API Key，也可以这样做：

### 1. 登录新 GPT 账号

打开 ChatGPT，用新的 GPT 账号登录。

### 2. 发送产品图和描述

把妙手产品主图和产品描述发给 GPT。

视频提示词使用这段开头：

```text
你是TikTok带货视频脚本设计专家，擅长结合平台热门内容形式，基于产品信息生成精准适配的标准化分镜脚本。

目标国家：德国
视频时长：15秒
请基于我提供的产品图和产品简单描述，输出：
1. 核心信息分析
2. 标准化分镜表：| 镜号 | 景别/角度 | 运动 | 画面内容 | 音频 | 时长(秒) |
3. 画面风格总结
4. 音频风格总结

要求：前三秒必须有钩子，最后三秒必须有 CTA，整体适合 TikTok 带货视频。
```

### 3. 生成标题和标签

继续把同一张产品图和描述发给 GPT，使用德国标题提示词，让它输出：

```text
请作为德国 TikTok 短视频产品策划专家，基于产品图和描述生成：
1. 产品多维分析
2. 10 个德国本土化 TikTok 短视频标题，附中文翻译
3. 5-8 个德语话题标签

要求：真实客观，避免夸张营销，适合德国本土用户。
```

### 4. 去 TikTok Create 生成视频

1. 打开 TikTok Creative Studio。
2. 进入 Create。
3. 选择 Video。
4. 上传产品图。
5. 选择 Dreamina Seedance 2.0。
6. 设置 15s。
7. 粘贴 GPT 生成的视频分镜提示词。
8. 等待生成完成。
9. 下载视频。

### 5. 去 Neobund 放入待确认发布

1. 打开 Neobund。
2. 进入 TikTok Publish。
3. 选择对应账号。
4. 上传视频。
5. 填入 GPT 生成的德语标题和标签。
6. 保存为待确认。
7. 人工确认后再发布。

## 注意事项

- 不要用带真人脸的主图直接生成，TikTok 可能拒绝。
- 每个出单产品默认生成 10 个视频。
- 每个视频都必须进入待确认队列。
- 不要自动发布。
- 换 GPT 账号不会影响德国店铺发布规则。
